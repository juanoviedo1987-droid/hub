# Command Center · Juan Oviedo 🚀

Portal centralizado para acceso directo y seguro a todo el ecosistema de aplicaciones, paneles, tiendas y servidores desde cualquier dispositivo (móvil y desktop).

## Arquitectura
- **Frontend:** Single Page Application estática, ultra liviana, responsive y con diseño adaptado a PWA (Progressive Web App).
- **Alojamiento:** GitHub Pages (100% serverless, disponibilidad 24/7 sin servidor propio).
- **Fuente de Datos:** `links.json` (actualizado automáticamente por Antigravity o editable a mano).
- **Seguridad:** Acceso protegido por PIN personal de 4 dígitos.

## Actualización de Accesos
Para agregar o modificar un enlace, basta con editar `links.json` o solicitarlo en cualquier sesión de trabajo en Antigravity.
